# Temperature Converter

A simple and interactive temperature converter website built as part of my Oasis Infobyte Web Development Internship.

## Features

- Convert temperatures between Celsius, Fahrenheit, and Kelvin
- Input validation for invalid values
- Absolute zero validation
- Interactive temperature controls
- Responsive design for different screen sizes
- Animated and interactive UI elements

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## Project Structure

- `index.html` — Website structure
- `style.css` — Styling and animations
- `script.js` — Temperature conversion logic and interactions
