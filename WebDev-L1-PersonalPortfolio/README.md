# Personal Portfolio Website

A responsive personal portfolio website built to showcase my skills, projects, and experience in Frontend Development and Machine Learning.

## About the Project

This portfolio was created as part of the Oasis Infobyte Web Development Internship.

The website presents my background as a Computer Science and Artificial Intelligence graduate, along with my technical skills and selected projects in Frontend Development, Machine Learning, Computer Vision, and NLP.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Sticky navigation bar
- Smooth scrolling between sections
- Mobile navigation menu
- Active navigation link based on the current section
- Scroll reveal animations
- Animated job title
- Project filtering by category
- Interactive hover effects
- Back-to-top button
- Contact section with email, LinkedIn, and GitHub links
- Animated landmark-style visual inspired by MediaPipe hand tracking

## Sections

- Home
- About
- Skills
- Projects
- Contact

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- Canvas API
- Intersection Observer API

## Projects Featured

### Wasla
A real-time Egyptian Sign Language recognition system using MediaPipe, facial emotion detection, and deep learning.

### E-Commerce Website
A responsive e-commerce website built with Next.js, including product browsing, authentication, and REST API integration.

### University Landing Page
A responsive university landing page built with React, featuring reusable components, interactive sections, and Web3Forms API integration.
