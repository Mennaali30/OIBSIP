# NeuraFlow — AI Productivity Landing Page

A modern, responsive landing page designed for **NeuraFlow**, a fictional AI-powered productivity and workflow platform.

This project was developed as part of the **Oasis Infobyte Web Development and Designing Internship — Level 1, Task 1 (Landing Page)**.

## 🌐 Live Preview

> Add your live demo link here after deployment.

## 📌 About the Project

NeuraFlow is a conceptual productivity platform designed to help users organize ideas, manage their workflow, focus on important tasks, and turn goals into meaningful results.

The landing page presents the product through a clean and modern interface built around the workflow:

**Capture → Sort → Focus → Ship**

The project focuses on creating a visually polished, responsive, and user-friendly static landing page using HTML5 and CSS3.

## ✨ Features

* Sticky navigation bar with smooth scrolling
* Hero section with headline, description, and call-to-action buttons
* Interactive workflow visualization using SVG
* Process section presenting three core stages
* About section describing the NeuraFlow concept
* Animated scrolling marquee
* Responsive layout for desktop, tablet, and mobile screens
* Custom typography using Google Fonts
* Consistent dark purple, lime, and coral color palette
* Hover effects and subtle CSS animations
* Footer with Email, LinkedIn, and GitHub links
* Accessibility-friendly focus states
* Reduced-motion support using `prefers-reduced-motion`

## 🛠️ Technologies Used

## 🎨 Design

The design uses a dark, modern visual identity with:

* Deep purple background
* Lime green accent color
* Coral secondary accent
* Serif typography for major headings
* Monospace typography for labels and navigation
* Responsive cards and layouts
* Custom SVG workflow visualization

## 📱 Responsive Design

The landing page is designed to work across different screen sizes.

The layout adapts for:

* Desktop
* Tablet
* Mobile

CSS media queries are used to reorganize the hero, process cards, navigation, and footer for smaller screens.
